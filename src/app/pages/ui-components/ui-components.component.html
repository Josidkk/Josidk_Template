Snackbars

Notificaciones con efecto glass y iconos

Clases disponibles:

  • snackbar-panel — Contenedor posicionado arriba a la derecha
  • snackbar-container — Fondo glass/blur con ícono y texto
  • .snackbar-success / .snackbar-error / .snackbar-warning / .snackbar-info — Variante de color

Uso: this.notify.success('Mensaje') — inyectar NotificationService

Confirmaciones

Diálogos modales con efecto glass

Estructura del componente:

  • .confirm-dialog — Contenedor con padding, ícono, título y acciones
  • .dialog-close — Botón X para cerrar (posicionado absoluto)
  • .dialog-icon.danger / .warning / .info — Icono circular con color semántico
  • .btn-confirm.danger / .warning / .info — Botón de acción principal

Uso: this.dialog.open(ConfirmDialogComponent, { data: { title, message, type } })

Modal Genérico

Modal reutilizable con icono, título, mensaje y acciones

Uso: this.dialog.open(InfoDialogComponent, { data: { title, message, icon } })

Componente reutilizable en shared/info-dialog/
